# 🤖 Neurolinks Documentation

Bienvenido a la documentación técnica de **Neurolinks**, una solución avanzada de chatbot para WhatsApp integrada con Inteligencia Artificial (OpenAI), Google Sheets, Calendario y una interfaz de administración web tipo Dashboard.

Esta documentación está diseñada para proporcionar a los desarrolladores y administradores toda la información necesaria para configurar, operar y extender las capacidades del bot.

## 🚀 Guía Rápida

Neurolinks es un bot de WhatsApp construido sobre el framework **BuilderBot**, utilizando el proveedor **Baileys**. Está diseñado para ejecutarse en entornos de nube como **Railway** y utiliza **Supabase** para la persistencia de sesiones.

### Tecnologías Principales
- **Backend**: Node.js (TypeScript)
- **Bot Framework**: [@builderbot/bot](https://builderbot.app/)
- **Provider**: Baileys
- **AI**: OpenAI Assistants API
- **Base de Datos**: Supabase (PostgreSQL)
- **Infraestructura**: Railway
- **Integraciones**: Google Sheets, Google Calendar, Google Maps

---
> **Nota**: El sistema utiliza un Dashboard web para facilitar el escaneo del código QR y la gestión de variables en tiempo real sin necesidad de acceder a la consola de Railway.
